# KG 로컬 탐색기

Neo4j 활성 세대의 전체 노드·관계를 캔버스로 확인하는 **개발·데이터 진단 도구**입니다.
제품 클라이언트나 배포용 API가 아니며, `Re_client → Re_server → Re_ai` 호출 계약을
변경하지 않습니다. DB 인증 정보는 로컬 Python 프로세스에만 있습니다.

## 실행

저장소 루트에서 기존 개발 환경을 설치하고, `.env`의 Neo4j 설정과
[KG 적재](../../docs/knowledge-graph.md#실행)를 완료합니다.

```bash
pip install -e '.[dev]'
docker compose -f docker-compose.neo4j.yml up -d --wait
resource-kg import
python -m scripts.kg_explorer.export_graph
uvicorn scripts.kg_explorer.server:app --host 127.0.0.1 --port 8020
```

**http://127.0.0.1:8020/** 에 접속합니다. 실행은 로컬 주소에 한정하세요.
다른 사이트에 공개하거나 제품·운영 환경에 배포하는 구성은 포함하지 않습니다.

Windows에서는 저장소 루트에서 다음 스크립트도 사용할 수 있습니다.
이미 적재된 Neo4j와 `.venv`가 필요합니다. 처음 실행할 때 내보낸 데이터가 없으면
전체 스냅샷을 생성하고 서버를 현재 터미널에서 실행합니다. `Ctrl+C`로 종료합니다.

```powershell
powershell -ExecutionPolicy Bypass -File scripts/kg_explorer/start.ps1
```

데이터는 이 폴더의 `.data/`에 생성되며 Git에서 제외됩니다. 저장소에 그래프 덤프,
비밀번호, 개인 경로, 프로세스 로그를 포함하지 않습니다. 새로 clone한 환경에서는
예제 화면을 대신 띄우지 않고 실제 그래프를 먼저 내보내도록 안내합니다.

## 탐색

- **유형별 구조**: 유형 노드와 관계 집계를 표시합니다. 원을 클릭하면 유형의 노드 수,
  관계 방향, 실제 노드 예시를 확인합니다. 선을 클릭하면 관계 유형과 집계 수를 확인합니다.
- **전체 그래프**: 샘플링 없이 모든 개별 노드와 관계를 WebGL로 표시합니다. 유형과 관계
  필터, 확대·축소, 드래그 이동, 화면 맞춤, 전체 화면을 사용할 수 있습니다.
- **소재·검색**: PP·PET·PE·알루미늄·종이를 선택하거나 전체 노드의 이름·ID를 검색합니다.
  검색 결과는 일치 개수를 표시하고 목록에는 25개까지 보여줍니다.
- **주변 탐색**: 선택 노드에서 방향과 무관하게 1~3단계 이내를 찾고, 원래 관계 방향을
  보존해 표시합니다. 이 보기만 6,000노드 상한이 있으며 적용 시 화면에 알립니다.
  전체 그래프와 JSON 다운로드에는 탐색 상한이 없습니다.
- **노드 상세**: 들어오는/나가는 관계, 이웃 노드 목록, 원본 속성과 포함된 URL을
  확인합니다. 이웃 목록은 처음 60개까지 표시합니다. 더블클릭하면 탐색 중심을 옮깁니다.
- **저장**: 전체 JSON을 다운로드하거나, 현재 캔버스 PNG 미리보기를 열어 저장합니다.

노드 위치·거리는 가독성을 위한 배치이며 실제 공정 순서·유사도·지리 좌표가 아닙니다.
간선은 적재된 주장을 연결할 뿐, 공정 적합성·법적 허용·업체 인수 승인을 의미하지 않습니다.
원문 공정명 묶음, 추출 미검증 상태, 누락 값, PP·PE의 조건부 경로 부재도 보존합니다.
WebGL 미지원 시 Canvas 2D로 표시하므로 대용량 탐색 성능은 환경에 따라 달라집니다.

## 갱신과 검증

원본 그래프의 세대는 `.data/manifest.json`에 기록됩니다. 원본 속성은 같은 세대에서만
조회합니다. 다른 세대가 감지되면 409와 새로고침 안내를 반환합니다. Neo4j가 꺼져도
저장된 전체 그래프는 표시되며 원본 속성 조회는 503을 반환합니다.

**탐색기 서버를 종료한 뒤** 내보내기를 다시 실행하고 서버를 재시작하세요.
내보내기는 하나의 읽기 트랜잭션에서 활성 세대와 전체 노드·관계를 읽습니다.
중복 ID, 누락된 연결 대상, 온톨로지 관계, 세대 매니페스트의 유형별 개수를 검사합니다.
파일 3개를 교체하므로 내보내는 도중에는 서버를 실행하지 마세요.

```bash
python -m scripts.kg_explorer.export_graph
pytest -q tests/unit/test_kg_explorer.py
ruff check .
ruff format --check .
```

초기 로컬 검증에서는 13개 노드 유형, 14개 관계 유형에 속하는 노드 83,557개·관계
169,712개의 전체 표시와 유형별 집계 23개를 확인했습니다. PP 3단계는 207노드·244관계,
PET 3단계는 614노드·910관계였습니다. 이 수치는 당시 스냅샷의 결과이며 상수가 아닙니다.
브라우저에서 검색→주장→근거 이동, 원본 속성, 필터 복원, 노드 클릭과 PNG 생성도
확인했습니다. 자동 테스트는 스냅샷 무결성과 읽기 전용 API의 회귀를 검증합니다.
