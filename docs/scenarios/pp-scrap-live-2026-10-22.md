# 검정 PP 스크랩 3톤: 실제 DB 연결 실행 결과

**결과: 세 공정 경로를 찾았고, 모두 REVIEW(확인 필요)로 반환했습니다.**

배출 로트는 시연을 위한 가정입니다. 실제 기업이 제공한 문서·견적은 없습니다.
실제 로컬 Neo4j와 공식 법령이 적재된 PostgreSQL/pgvector를 사용했고, 가짜 검색 응답·가짜 가격·가짜 탄소 계수는 넣지 않았습니다.
생성 모델은 호출하지 않았으며 로컬 multilingual-e5-small 임베딩을 사용했습니다.

## 입력한 업무

> 공장에서 검정 PP 스크랩 3톤이 발생했다. 가능한 재활용 공정·시설 경로와 각 단계의 확인 사항을 찾아 달라.

수분·오염도·지정폐기물 여부·발생지·시료 분석서는 미확인으로 두었습니다. 기존 처리 경로는 가정하지 않았습니다.
자연어 추출·OCR를 시험한 것이 아니라 아래 구조화 입력으로 API 핸들러를 실행했습니다.

```json
{
  "research": {
    "lot": {
      "material": "PP",
      "input_form": "scrap",
      "quantity_kg": 3000,
      "color": "검정",
      "page_size": 1
    },
    "max_pages": 20,
    "max_legal_queries": 100,
    "legal_top_k": 3
  }
}
```

`POST /analysis/review-template`으로 빈 수치 양식을 만들고, `POST /analysis/review`에 위 입력을 전달했습니다.
FastAPI TestClient로 실제 API 핸들러를 실행했으며, 서비스 의존성을 가짜로 교체하지 않았습니다.

## 실제로 나온 공정·시설 후보

| 후보 | 공정 순서 | KG가 연결한 조사 대상 | 결과 |
| --- | --- | --- | --- |
| A | 반입 선별·파쇄 → 파쇄품 | 중앙이엔비 공주 사업장 | REVIEW |
| B | 반입 선별·파쇄 → 세정 조사 → 압출 재생 → 재생 펠렛 | 중앙이엔비 공주 → BGF에코사이클 재생원료사업장(예산) | REVIEW |
| C | B의 공정 → 컴파운딩 → 재생 컴파운드 | 위 조사 대상 → BGF에코사이클 컴파운드사업장(화성) | REVIEW |

세 후보는 공통 선별·파쇄 경로에서 **어느 산출물 단계까지 처리할지**가 달라지는 후보입니다.
서로 독립적인 세 가지 기술이나 실제 기업 사이의 거래 계약을 검증한 결과가 아닙니다.
파쇄품·펠렛을 산출한다고 실제 매각처와 가격이 확보되는 것도 아닙니다.

중앙이엔비의 PP 품목·공주 사업장·선별/파쇄 공정은 [회사 공개 자료](https://www.jungangenb.com/process)를 근거로 연결했습니다.
BGF의 [재활용 소재 자료](https://www.bgfecomaterials.com/kr/company/business/recycle)는 세척·압출·컴파운딩과 재생 PP 사업을 소개합니다.
하지만 이번 KG의 예산·화성 **개별 사업장 수행 공정 연결은 `site_role_hypothesis`(조사 가설)**입니다.
해당 시설이 검정 PP 3톤을 실제로 받아 처리한다는 확인으로 승격하지 않았습니다.

이번 경로 생성은 별도로 구축한 국내 공정·상태 전이·시설 참조 KG를 사용합니다.
W2RKG 문헌 전체를 새로 조사하거나 전국 시설 명부 전체에서 최적 사업장을 찾은 실행은 아닙니다.

## 단계별로 무엇을 돌렸나

| 단계 | 이번 실행 결과 |
| --- | --- |
| KG 탐색 | 3페이지에서 세 후보 모두 수집. 등록 PP 범위 안의 전체 조회 완료 |
| 공개 조건 대조 | 원래 로트와 예상 후속 상태를 구분. 색상·수분·오염·분류·수용 물량·허가·인수 조건은 확인 필요 |
| 법령 검색 | 중복을 합친 질문 10개를 모두 실행하고 각 질문에서 검색 결과 수신. 예산 초과·검색 장애 없음 |
| 법규 적용성 Auditor | 이번 실행에는 미사용. 검색 성공을 법규 적용 검증 완료로 처리하지 않음 |
| 비용·탄소 계산 | 견적·활동량·운송·LCI 근거 미제출. 총액·배출량·Pareto·최종 순위를 생성하지 않음 |
| Critic·분기 | 구조·조건·미확인을 결정론적으로 검사. REVIEW와 다음 행동 반환 |
| 출력 | 후보별 검토 보고서와 공정/인계 구간에 연결할 마커 데이터 반환. 실제 3D 화면 연동은 미시험 |

검색 결과에는 폐기물관리법 제17·25·48조, 시행규칙 별표 4·4의3·5의3과 판례 등이 포함됐습니다.
이는 검색된 근거 후보 목록입니다. 필요한 모든 조항·예외가 모였거나, 이 로트·시설에 적용된다는 판정이 아닙니다.
시설 허가 질문 일부는 판례·재활용 유형 위주로 검색돼 핵심 허가 조문·항의 충분한 회수 여부를 추가 검수해야 합니다.

## 사용자가 받는 확인 목록

아래 여섯 묶음은 이번 결과를 사람이 읽기 쉽게 정리한 것입니다. 서비스가 여섯 범주로 자동 집계한 것은 아닙니다.

| 확인할 것 | 지금 모르는 것 | 다음 행동 |
| --- | --- | --- |
| 폐기물 분류 | 지정폐기물 여부, 정확한 분류·성상 | 발생 공정·성분 분석서로 분류 확인 |
| 품질 | 검정 색소·충전제, 이물·수분, 후속 공정 투입 규격 | 분석서·시료와 시설 수탁 규격 확보 |
| 시설 수행·허가 | BGF 사업장별 실제 공정, 현행 허가 품목·규격 | 사업장별 수행 공정 자료와 허가 범위 대조 |
| 인계·운송 | 파쇄품 세척 상태, 다음 시설 수용, 발생지·도로거리 | 양쪽 인계 규격과 발생지·배차/운송 조건 확인 |
| 수익·비용 | 처리·전처리·운송·잔재물 비용, 산출물 매각 수익 | 같은 로트 기준의 실제 견적·매각 조건 확보 |
| 탄소 | 공정별 활동량·수율·잔재물, 적용 가능한 LCI/배출계수 | 국가·연도·단위·경계·공정 일치 검수 후 계산 |

원시 출력에는 마커 101개가 있습니다. 세 경로의 공통 공정을 반복 검사한 항목을 포함하며 **독립적인 사고·리스크 101건이라는 뜻이 아닙니다.**
대상별로 공정 87개·인계 구간 5개·후보 전체 9개입니다. 모두 확인 과제이며 실제 사고 발생 확정은 없습니다.
화면에서는 같은 공정·확인 주제를 묶고 세부 항목을 펼쳐 보는 방식이 필요합니다.

## 입력을 바꿨을 때도 확인

같은 시연 로트에서 `designated_waste=true`로 바꾼 별도 요청도 실행했습니다.
중앙이엔비의 공개 지정폐기물 제외 조건과 충돌해 `facility_designated_waste`가 발생했고, `REVISE`와 `restart_from=validation`을 반환했습니다.
[공개 제외 정책](https://www.jungangenb.com/process)을 확인한 결과이며 실제 로트가 지정폐기물이라는 판단을 한 것은 아닙니다.
세 후보는 목록에 보존했고 수정할 조건을 표시했습니다.

## 이번 시나리오가 보여 준 현재 수준

**후보 경로와 근거·확인 목록을 만드는 단계는 실제 DB로 실행됩니다.**
이 사례에서 어디가 가장 싸고 탄소가 적은지 정하는 데 필요한 실제 수치와 사업장 수탁 근거는 확보되지 않았습니다.
특히 BGF의 사업장별 공정·인수 확인, 같은 로트의 견적·활동량·LCI, 법령 핵심 조항 회수와 적용성 검증을 채워야 합니다.

연결·미확인 보존·변형 입력 처리에 대한 행동 검사 7개는 통과했습니다. 추천 정확도·법규 적합성·현장 인수 성능 시험은 아닙니다.
