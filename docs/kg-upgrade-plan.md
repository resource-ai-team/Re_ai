# KG 고도화 계획과 실행 결과

기준 파이프라인: [2026-10-20-fixed-v1](pipeline-baseline.md). GitHub 작업: #10.

KG의 일은 **가능성을 조사할 후보와 근거를 빠짐없이 제공하는 것**입니다.
KG가 적법성·경제성·탄소 순위를 미리 결론내리지 않습니다.

## 이번에 실행한 것

| 발견한 문제 | 바꾼 동작 |
| --- | --- |
| 문헌 기본 20건만 보고 전체 후보로 오해할 수 있음 | 새 전체 조회 API에 전체 건수·유형별 건수·다음 페이지를 제공. 최종 K개 선정과 분리 |
| 입력 형태를 모르면 다른 형태의 템플릿이 숨겨짐 | 모든 형태 후보를 보존하고 미확인·다른 형태·같은 표현 여부만 표시 |
| ReAct가 공정·조건·근거를 다시 조립해야 함 | 후보별 조사 묶음에 단계·구간·리스크 대상·조건·근거·확인 과제를 함께 제공 |
| 일반 법규·경제성 카드를 특정 소재와 연결하지 않아 놓칠 수 있음 | `multiple` 범위 카드를 배경 자료로 포함. 그 소재에 적용된다는 주장과 구분 |
| 다른 경로의 단계에 리스크가 붙을 수 있음 | 실제 Neo4j의 경로 소속·구간 연결·리스크 대상·근거를 응답 전에 대조 |
| 조사 질문이 자동 제외 규칙으로 오해될 수 있음 | 조건을 `unassessed`, `machine_rule_ready=false`로 표시. KG 단계의 판정값은 `null` |
| 페이지마다 그래프나 입력이 바뀌면 서로 다른 후보가 섞임 | 그래프 버전·namespace·입력·내부/외부 보기 방식에 묶인 커서 사용 |
| 근거의 외부 전송 가능 여부가 섞임 | 에이전트 도구는 외부 모델용 보기 강제. 전송 불허 근거가 포함된 묶음은 본문을 가리고 ID만 보존 |

이 작업은 기존 데이터의 **조회·연결·검증 방식**을 고도화했습니다.
새로운 국내 PP·PE 공정이나 가격·탄소 수치를 추가했다고 주장하지 않습니다.

실행: `POST /kg/candidate-pool` 또는 `get_candidate_pool_page()`.
페이지 처리와 응답 예시는 [조사 묶음 API](kg-research-pool.md)에 있습니다.

## 다음 데이터 보강 순서

### 1. 검정 PP 사출 스크랩의 공정 후보부터 채우기

현재 PP는 W2RKG 문헌 후보만 있고 상세 공정 템플릿은 없습니다.
검정색을 인식하는 선별 설비가 있는지, 혼합 수지·첨가제·오염이 어떤지 확인해야 합니다.

- 공식 기술 문서와 원문 논문에서 **직접 확인한 순서만** 단계로 작성합니다.
- 선별·재가공 등의 경로가 확인되면 입력 상태와 필요한 전처리를 구분합니다.
- 각 단계와 인계 구간에 확인 질문·적용 범위·출처 위치·다음 행동을 붙입니다.
- 논문 실험을 국내 상용 공정·공장 인수 가능성으로 바꾸지 않습니다.
- 경로 수를 맞추려고 비슷한 업체나 이름만 바꾼 경로를 추가하지 않습니다.

완료 기준: 확인한 경로의 모든 단계·구간·리스크에 출처가 연결되고,
실험/상용 사례/가상 입력이 구분되어야 합니다. 공정 분야 검수 전에는 조건부로 유지합니다.

### 2. PE를 HDPE·LDPE·LLDPE와 형태별로 구분하기

현재 PE는 검색용 수지군입니다. HDPE를 넣었다고 모든 PE 공정이 적합한 것은 아닙니다.
필름·용기·파쇄물의 형태와 수지 등급을 분리해 자료를 모으고, 이를 확인할 질문을 추가합니다.

완료 기준: 수지·형태가 다르거나 모르면 그 차이가 표시되고,
전문가 검수된 조건 없이 자동 제외·통과하지 않아야 합니다.

### 3. 법규·업체·수치를 연결할 때의 조건을 채우기

| 자료 | 필요한 정보 | 데이터가 없을 때 |
| --- | --- | --- |
| 국내 법령 | 현행 원문·시행일·폐기물 분류·허용 재활용 유형·예외·시설 허가 범위 | 법규 추가 확인 |
| 업체 | 처리 가능한 투입물·품질·용량·현재 허가·확인일·서면 인수 조건 | 업체 예시이며 인수 미확인 |
| 비용 | 시점·지역·물량·가격 단위·전처리·운송·잔재물 비용 | 계산 불가 항목 표시 |
| 탄소·LCI | 기능단위·지역·연도·기술·산정 범위·배분·회수율·운송·잔재물 | 비교 불가 또는 제한된 시나리오 표시 |

다운로드한 LCI 원본은 이용 조건을 확인한 저장소에서 관리합니다.
KG에는 사용 가능한 메타데이터·출처·범위부터 연결하며, 이 PR은 LCI 숫자 계산을 구현하지 않습니다.

## 다음 기술 보강 순서

1. 후속 실행기가 모든 KG 페이지를 수집하고 `candidate_id`로 추적하게 연결합니다.
2. ReAct ①이 각 확인 질문에 원문·입력 사실·적용 범위를 붙여 답하도록 만듭니다.
3. **조사 질문과 검수된 실행 규칙을 별도로 관리**하고, 그 이후에 조건 판정기를 붙입니다.
4. 비용·탄소의 값·단위·지역·시점·범위가 맞을 때만 계산기에 전달합니다.
5. 최대 K개 비교와 지도에 후보 ID·단계 ID·리스크 대상 ID·그래프 버전을 그대로 전달합니다.

현재 API는 **연결 준비**까지입니다. 모델이 조회·반박을 실제 수행하는 ReAct 실행기는 아직 없습니다.
외부 전송이 불허된 근거는 다른 허용 자료를 찾거나 내부 검토로 처리해야 합니다.

## 검증 방식

- 단위 검사: 미확인 입력·잘못된 커서·과도한 페이지 크기·외부 전송 경계·HTTP 오류 구분.
- 실제 Neo4j: 후보 누락·중복, 형태 미확인 보존, 근거 연결, 다른 경로의 리스크 대상 차단.
- 전체 자료 검사: 5개 소재군에서 모든 페이지를 받고, 고정 원본에서 계산한 ID 집합과 비교.
- 검사 보고서: [kg-pool-2026-10-20.json](evaluation/kg-pool-2026-10-20.json).

전체 원본 대조 검사 **82/82 통과**. 아래 공정 수는 입력 형태별 버전까지 센
조건부 템플릿 수이며, 서로 다른 상용 공정 수나 추천 가능한 업체 수가 아닙니다.
조사 카드에는 각 소재의 직접 카드와 공통 배경 카드 10개가 포함됩니다.

| 소재군 | 문헌 관계 | 조건부 공정 템플릿 | 직접·배경 조사 카드 |
| --- | ---: | ---: | ---: |
| PET | 161 | 5 | 15 |
| 알루미늄 | 57 | 8 | 54 |
| 종이 | 180 | 5 | 18 |
| PP | 60 | **0** | 10 |
| PE | 144 | **0** | 10 |

**PP·PE에 대해 상세 공정 지도를 생성할 수 있게 됐다는 뜻은 아닙니다.**
지금은 문헌·배경 자료와 부족한 확인 과제를 넘기는 단계입니다.

위 검사는 **조회와 연결의 정확성**입니다. 최종 추천 정확도·법률 판단·공장 적용을 입증하지 않습니다.
추천 검증은 검수자가 정리한 사례에서 가능한 후보의 잘못된 제외,
불가능한 후보의 잘못된 통과, 근거 누락과 비용·탄소 계산 오류를 별도로 측정해야 합니다.
